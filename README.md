# Public output catalog

This repository holds the public, externally published view of the
Brightwater Applied Learning Lab's research outputs.

`catalog/<cycle>-outputs.json` is maintained by research operations after the
internal disclosure for each project has been filed. Each output entry carries
title, venue, authors, a completion status, and an optional `code_url`.

`code_url` is optional by policy: it is populated only when the corresponding
source repository has already been publicly released. Entries without a public
release keep `code_url` empty.
